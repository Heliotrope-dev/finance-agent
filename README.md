# Invest Agent

面向沪深、港股、美股与加密资产的个人投研工作台。它把“关注一只标的”整理为可复核的研究、计划、提醒与复盘流程；所有真实交易均由用户在券商端手动执行。

在线体验：[invest.heliotrope.online](https://invest.heliotrope.online)

> 仅供研究与教育用途，不构成投资建议或收益承诺。系统不会连接、控制或代替用户的真实交易账户下单。

## 核心能力

- **每日可执行清单**：将研究观点与入场区间、止损、目标、盈亏比和仓位约束分开呈现；只有通过硬性风控条件的标的才会进入计划。
- **多市场研究**：统一查看股票、指数、ETF 与加密资产的行情、技术面、财务、估值、机构观点和事件。
- **自选与持仓**：支持关注列表、真实持仓记录、到价提醒，以及组合暴露、相关性、波动率、Beta、VaR/CVaR 与压力测试。
- **模拟盘**：使用独立的虚拟资金和模拟账户记录 AI 决策、成交、净值与复盘，不触及真实资金。
- **判断追踪**：保留生成时价格与后续复核结果，区分研究观点、可执行计划与实际结果。
- **研究助理**：基于实时工具数据回答问题；缺少可靠数据时应明确说明，而不是编造事实。

## 设计原则

### 代码负责事实与算术

入场区间、止损、目标、盈亏比、仓位规模、汇率换算、实际港股手数与数据分类均由确定性代码计算。模型用于研究、解释和提出待验证假设，不承担可被程序可靠计算的任务。

### 先控风险，再做排序

候选标的先经过盈亏比和风险档案阈值，再在合格集合中按研究分数排序。数据缺失、手数超出预算或时间尺度不匹配时，系统应降级为观察，而不是把不完整信息包装成买入建议。

### 保留上下文与证据

每条判断均关联时间、价格与数据口径。页面区分“计划生成时价格”和“最新报价”，避免用之后的行情改写当时的决策依据。

## 工作流

```text
行情与公开数据
        |
        v
确定性指标、风险与仓位计算
        |
        v
AI 研究与多空论证
        |
        v
观察列表 -> 可执行计划 -> 手动交易
        |                       |
        +------> 提醒与复盘 <----+
```

## 技术栈

- Python、Streamlit、Plotly、pandas
- Futu OpenAPI：港美股与模拟盘行情/交易数据
- BaoStock、AkShare 与公开网页资料：补充历史和基础数据
- Gemini 及可配置模型回退：研究与解释
- Supabase：用户、持仓、判断追踪与模拟盘数据

## 本地运行

```bash
git clone https://github.com/Heliotrope-dev/finance-agent.git
cd finance-agent
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

在 `.streamlit/secrets.toml` 配置本地的模型、数据库和可选数据源凭据。该文件不得提交。需要港美股实时数据时，在本机运行 Futu OpenD；服务不可用时，应用会以可用的延迟数据或降级状态展示，而不会把缺失数据伪装成实时行情。

## 重要边界

- `shares = 0` 表示自选，`shares > 0` 才表示真实持仓。
- 港股使用实际每手股数；报价币种不等同于公司财务报表币种。
- 模拟盘与真实持仓严格隔离。
- 策略统计样本不足时显示“尚未验证”，而非输出虚假的精确胜率或期望值。
